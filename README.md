## 🧠 Three things building it taught me

**Adoption beats elegance.**
The hardest problem in the warehouse system was never technical. Twenty people already lived in Excel, and any system that took Excel away would have been quietly abandoned in a month. So the system imports and exports to Excel instead of replacing it. They kept the tool they knew; the warehouse got centralized querying and traceability. The "correct" solution — migrate everyone off spreadsheets — would have shipped and then died.

**Permissions are a data model problem, not a feature.**
I spent six months auditing IAM policies for a FinTech platform, applying least privilege to a real production account. What stuck with me is that access control is almost impossible to bolt on later. In the warehouse system, RBAC was in the schema from the first migration, because institutional audit requirements aren't something you retrofit.

**Owning the whole stack makes you conservative about complexity.**
When you write the migration, the API, the UI *and* run the deploy, you feel every clever decision twice — once building it, once at 11pm when it breaks. I've become much more willing to write the boring version.
